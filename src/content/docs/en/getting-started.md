# Getting started

This guide is an example. Replace the product name, domain, integration records and demo command before you publish.

## Name and domain

Edit `src/config/site.ts`. Set `name`, `url`, `repository` and the hero copy for each locale.

## Integrations

Edit `src/data/integrations.json`. Keep one record for `en` and one for `pt-br` for every slug. Use `https://` links and
optional screenshots under `public/images/`.

## Demo command

The install tabs read `site.install`. Change the example commands to the ones your tool actually documents. They are
displayed as text and are not executed.
